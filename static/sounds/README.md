# Alert sounds

Nine sounds are original offline synthesis for Agent Board, generated by
`tools/generate_alert_sounds.py` using Python's standard library. Fart uses the
owner-supplied recording. The generator leaves that file untouched and does not
create a synthesized replacement if it is missing.

The complete supplied recording was converted locally to mono PCM with a
constant gain adjustment. It was not trimmed, faded or synthesized. Only the
metadata-free WAV is included; the original compressed recording stays outside
the source and app bundle. No provider sound or external media service is used.
The canonical Fart WAV contains 6,912 frames at 22,050Hz (about 0.31347 seconds)
and has SHA-256
`da103b9e5a4936d572452c5c55f6e1acffc30ae05f2efeb3c6004d0b5b73aad5`.

Each file is mono, 22,050Hz, 16-bit linear PCM WAV and shorter than two seconds.
The dashboard plays these local files. Packaging also copies the same bytes to
the main app's Resources with `agent-board-` filename prefixes for native alerts.
Soft Ding preserves the previous 740Hz fade. No separate rights are granted to
Agent Board's own assets by the third-party software notices.
