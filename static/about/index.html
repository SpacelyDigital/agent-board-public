About Agent Board

Back to board

Agent Board keeps your Codex, ChatGPT, Claude Code and Claude chats visible while you work. See what is cooking, what needs your input and what is ready to review without checking each window.

How it works

The app reads activity from your existing Mac apps and shows each chat’s current status. Open takes you to the original chat. Reviewed clears the reply from your dashboard until there is new activity, without changing the conversation.

Optional account monitoring follows regular ChatGPT and Claude chats from the web or desktop app. It uses the account already signed in on this Mac and does not require an open chat window or Accessibility permission. Open returns to the original chat in your browser.

Your dashboard runs on this Mac’s loopback address. A local collector keeps it up to date, including when the dashboard window is closed. Quit Agent Board to stop monitoring.

Privacy

Agent Board does not send your chats, account details, usage statistics or diagnostics to Spacely Digital. It has no analytics, crash uploads or developer-operated server. Your board data stays on this Mac.

Optional account features make read-only requests to your existing providers for usage, Claude project activity, chat titles and reply status. Agent Board does not submit prompts, start model work or upload your local chat transcripts.

This build reads only the source folders you choose. It does not read saved sign-ins, submit prompts or upload your chat transcripts. Local usage readings, when available, come from information written by your provider apps.

What the app reads and stores

Local chat metadata and bounded session records provide titles, project paths, chat identifiers, timestamps, status and short reply or permission previews. The local database stores these fields, your review and snooze state, and your chosen names and placement. It does not copy full chat transcripts or tool output.

The database and service logs are in ~/Library/Application Support/Agent Board/data. Appearance, sound and notification preferences are stored locally in the display or Mac app settings.

The database and logs stay in Agent Board’s macOS app container. Choose Agent Board → Open Local Data Folder to find them. Appearance, sound and notification preferences also stay on this Mac.

Requests to your providers

Claude usage and project reads contact api.anthropic.com; regular chat metadata comes from claude.ai. These features use the Claude desktop account’s existing sign-in. The app reads the named Claude Safe Storage Keychain item to unlock the existing credentials in memory. Allow Claude Account Access lets you request Keychain permission; background reads never open permission prompts. It does not save, log or send that credential to the developer, and authenticated requests do not follow redirects.

Codex usage is read through its local app-server account interface using its existing sign-in. Codex handles its provider connection. Regular ChatGPT monitoring uses the existing OpenAI sign-in to read recent chat metadata and reply status from chatgpt.com. Its bounded latest-reply response can include message content; Agent Board keeps only reply identifiers, timestamps and completion status, then discards that response. It does not create an account, refresh a sign-in, write to a chat or run a model turn.

Usage readings

The usage meters show the most recent local reading, with its age and reset time. They cannot refresh a provider’s cached reading or confirm that an expired quota has reset. Connecting a local Claude usage export is optional.

Permissions and connections

The downloaded Mac app asks before it starts monitoring. Account usage, Claude cloud projects, notifications and launch at login are off until you choose them. Use Agent Board → Setup and Permissions to change those choices.

The app asks you to choose source folders before monitoring those apps. Notifications and launch at login are optional. Use Agent Board → Setup and Permissions to change those choices or forget folder access.

Notifications are optional and controlled by macOS. The dashboard listens only on this Mac’s loopback address.

You can include regular ChatGPT and Claude chats in Setup and Permissions. Monitoring requires the matching account’s existing sign-in on this Mac. Private local checkpoints preserve reply and review tracking across restarts. The account readers do not control the provider apps. The Claude reader accesses Claude Desktop’s saved session-cookie database and uses the named Claude Safe Storage Keychain item to decrypt its credential in memory. It does not read cookies from unrelated web browsers.

To remove stored board data, quit Agent Board and delete ~/Library/Application Support/Agent Board. Display settings and macOS notification preferences are separate.

To remove stored board data, open the local data folder, quit Agent Board and move that folder to Trash. Source chats are separate and remain unchanged. Display settings and macOS notification preferences are also separate.
