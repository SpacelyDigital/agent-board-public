About Agent Board

Agent Board keeps your local Codex and Claude Code chats visible while you work. See what is cooking, what needs your input and what is ready to review without checking each window.

How it works

The app reads activity from the source folders you choose. Open takes you to the original chat. Reviewed clears a reply from the board until there is new activity, without changing the conversation.

Usage meters show cached quota readings from local provider records. Claude usage requires an optional plugin that you install in Claude. Readings may be absent or old; a scheduled reset does not confirm a renewed allowance or the account currently signed in.

Monitoring continues when the window is closed. Quit Agent Board to stop monitoring.

Privacy

Agent Board does not send your chats, account details, usage statistics or diagnostics to Spacely Digital. It has no analytics, crash uploader or developer-operated server. It does not read saved sign-ins, send prompts or make provider account requests.
