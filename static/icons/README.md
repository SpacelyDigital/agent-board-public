# Provider marks

These local SVGs identify the providers in Agent Board's usage cards. They are not Agent Board branding.

- `codex.svg`: copied byte for byte from OpenAI's installed ChatGPT Mac app 26.1016.61520, `Contents/Resources/app.asar` member `webview/assets/codex_new-f14177b03534.svg`. Original 24 by 24 viewBox and path data are retained. This is the outlined Codex cloud and terminal mark.
- `claude.svg`: Anthropic's 24-unit Claude spark path (`Fh`, used by the `ClaudeLogo` component's 24-unit lockup), extracted from Claude Mac app 3.6556.2, `Contents/Resources/ion-dist/assets/v1/shared-1-BJhqMmkf.js`. Original path data and 24 by 24 viewBox are retained in a standalone SVG wrapper.

The application renders both marks as monochrome CSS masks to match its selected theme. No external requests, scripts, raster payloads, or references are included. Trademarks belong to OpenAI and Anthropic respectively.
