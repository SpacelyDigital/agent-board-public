# Agent Board

Agent Board shows which AI sessions are working, waiting for input, or ready to review. Open a session from the board or mark its reply reviewed to keep your queue clear.

| Edition | What it includes | Where to find it |
| --- | --- | --- |
| **Full Mac download** | Codex, Claude Code, regular ChatGPT and Claude chats, Claude projects, and account usage | [Download the current signed build](https://github.com/SpacelyDigital/agent-board-public/releases/latest) |
| **Mac App Store edition** | Local Codex and Claude Code sessions, including Claude Code in Claude Desktop | [Store engineering backup](https://github.com/SpacelyDigital/agent-board-public/releases/tag/store-0.2.5-build72-backup) |

The current full download is **0.2.5 build 68**, signed and notarized for Apple silicon Macs. Download the DMG or ZIP, place Agent Board in Applications, and follow Setup. Requires macOS 13 or later.

## Engineering backups

Both editions share a source tree and have separate packages. Build 72 is the latest tested engineering snapshot. Its artifacts are previews.

- [Full build 72](https://github.com/SpacelyDigital/agent-board-public/releases/tag/full-0.2.5-build72-backup) contains the full preview ZIP and DMG, source, and checksums.
- [Store build 72](https://github.com/SpacelyDigital/agent-board-public/releases/tag/store-0.2.5-build72-backup) contains the unsigned Store preview and the exact signed build 70 package and source sent to Apple. Build 70 is selected in the App Store Connect draft. The Store edition is still in preparation.

For exact source and package verification, use the release tag and its manifest. This README is the edition guide for the repository.
