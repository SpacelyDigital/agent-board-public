Support

The full direct-download version monitors local coding chats and offers optional account connections for regular ChatGPT and Claude chats, Claude projects and usage. A separate, reduced Store candidate reads local coding chats from selected folders. Neither version uploads your chats or diagnostics to Spacely Digital.

For help, email Spacelydigital@gmail.com. The link opens your mail app. Agent Board does not send a message or attach chats, logs or other data automatically.

My chats do not appear.

In the direct-download edition, check the monitoring choices in Setup and the source status shown on the board. Optional account connections require the corresponding provider's existing sign-in on this Mac. If access is unavailable, follow the reported instruction and confirm that the provider app is signed in. Unconfirmed activity remains unavailable.

In the App Store edition, open Agent Board → Setup and Permissions and select the source folders for Codex and Claude Code. For Claude Code in Desktop, choose Library/Application Support/Claude/claude-code-sessions in your home folder. Regular ChatGPT and Claude account chats are not included in this edition.

A chat is checking history or has no confirmed status.

Agent Board verifies local session records before confirming that work has finished. A large, incomplete or changing file may take longer. Leave the board open, then check the source app if its status remains uncertain. Agent Board does not assume a quiet chat is finished.

I see an old usage reading or no usage figure.

The direct-download edition can request usage through its optional account connections. Check Setup, the provider sign-in and any access or retry message on the board. The observation time and stale label indicate whether a reading is current. Agent Board never sends a prompt to refresh usage or assumes that a passed reset means a new full allowance.

The App Store edition shows Codex weekly usage only when a verified local session record contains it. Claude usage is not available in this edition, and no Claude plugin is included.

Notifications are not appearing.

Enable notifications in Agent Board and allow them in macOS System Settings under Notifications. Check Focus settings too. Monitoring still works when notifications are off or denied.

The chat link does not open the right place.

Open the coding tool directly and confirm the chat is still available. Exact-chat links depend on the provider app and its version. A reviewed or snoozed card changes only your board; it does not archive the original chat.

I want to stop monitoring or remove local data.

In the App Store edition, use Forget Source Folders in Setup to stop reading those folders and remove their saved permissions. Your board history, names and review choices are retained. In the direct-download edition, disable optional account monitoring in Setup to stop those account requests. Quit either edition to stop its collector. To remove the board's database and logs, first choose Open Local Data Folder, then quit the app and remove that folder. Your provider chats stay separate. Appearance settings and notification preferences are separate local stores.

Agent Board does not need your chats, passwords or diagnostic files for these steps.
